## 2. Detailed Breakdown of Each Display Item

### Table 1: Pre-Registration, Pilot Gates, and Verification Record
- **Goal:** Provide full scientific transparency on the pre-registration timeline, the pilot 1 failure under the frozen rule, the amendment 1 confirmation pilot 2 pass, the secrecy re-pilot, and independent two-rater hand-check agreements.
- **Source CSVs:**
  - Pilot 1: `runs/pilot/pilot_table.csv` (Report 08)
  - Pilot 2: `runs/pilot2/pilot_table_amendment1.csv` (Report 09b)
  - Hand-check: `runs/pilot2/handcheck_uptake_filled.csv` (Report 09b §12)
  - Re-pilot: `runs/repilot_secrecy/pilot_table.csv` (Report 09c)
- **Columns:**
  - `Phase / Pilot`: Pilot 1 (frozen rule v1), Pilot 1 (retrospective v2), Pilot 2 (Amendment 1 gate), Re-pilot v4.
  - `Games (T1 / T2)`: Counts of positive and negative games.
  - `Uptake Rule`: Pass rate (threshold ≥ 0.5 per game and ≥ 1 cell per agent).
  - `Falsification`: Pass rate on Type 2 decoy pairs (must be 0).
  - `b1 Strictly Top coGO`: Fraction of Type 1 games where focal pair co-went more than any other pair.
  - `b2 Coalition Advantage`: Fraction with $G_{\text{others}} > 0$ and capture in $\ge 2$ rounds.
  - `Hand Agreement`: Cell agreement % and Cohen's $\kappa$.
  - `Overall Status`: Gating PASS / FAIL.

### Table 2: Dataset Composition, Quality, and Manipulation Check
- **Goal:** Document sample size per condition, dev/test split balance, token parse failures, language compliance, leak scan flags, and the frozen manipulation check.
- **Source CSVs:**
  - Metadata: `data/labels.csv` and `data/split.json`
  - Cleaner flags: `data/clean/leak_flags.jsonl`
  - Run logs: `runs/dataset/dataset_quality.csv` (Report 12 TBD)
- **Columns:**
  - `Episode Type`: Type 1 (Collusion), Type 2 (Honest), Type 3 (Talk-only lookalike), Type 4b (Same-incentive lookalike).
  - `Total Games (Dev / Test)`: Counts per condition.
  - `Valid Rounds (%)`: Percentage of rounds with all 5 valid actions parsed.
  - `Truncation / Parse Failures`: Count and % of calls hitting `num_predict`.
  - `Non-English Texts`: Count of non-ASCII drifted outputs.
  - `Public Reveals (%)`: Fraction of focal public messages exposing the alliance.
  - `Leak Scanner Flags`: Count of retained flag-only terms (e.g. deposit mentions).
  - `Manipulation Check Pass (%)`: Uptake rule v2 pass rate on Type 1 games.

### Table 3: Primary Monitor Performance Across Views (Test Split)
- **Goal:** Report baseline collusion detection performance for an LLM monitor (`llama3.1:8b`) across all 8 information representations.
- **Source CSV:** `study_2_2_views/results/rq1_per_view_test.csv`
- **Columns:**
  - `View`: V1 (Messages), V2 (Actions), V3 (Raw Combined), V4 (Structured Report), V5 (Oracle Private), C-mismatch, C-length, C-shuffled.
  - `n Evaluated (Failed)`: Sample size and dropped failed outputs.
  - `AUROC`: Test set Area Under the ROC curve.
  - `95% CI`: Stratified bootstrap confidence interval ($B = 2000$, whole games).
  - `Threshold`: Score cutoff determined strictly on the dev split (max balanced accuracy).
  - `Accuracy`: Overall accuracy at frozen threshold.
  - `TPR (Sensitivity)`: True positive rate at frozen threshold.
  - `FPR (Fallout)`: False positive rate at frozen threshold.

### Table 4: Paired Hypothesis Tests & Information Views (Test Split)
- **Goal:** Formally test whether combining words with actions beats either alone (RQ2, Main Question), whether semantic coupling matters (RQ4), whether structured synthesis improves detection (RQ5), and whether private thoughts provide an oracle upper bound (RQ6).
- **Source CSV:** `study_2_2_views/results/rq2_rq4_rq5_rq6_rq7_paired_test.csv`
- **Columns:**
  - `RQ`: RQ2, RQ4, RQ5, RQ6, RQ7.
  - `Hypothesis Comparison`: Arm A vs Arm B (e.g., V3 vs Best Single View [V1/V2 chosen on dev]).
  - `Type`: Pre-registered Primary (RQ2, RQ5) vs Exploratory.
  - `Common n`: Paired sample size evaluated under both views.
  - `AUROC A`: Performance of Arm A.
  - `AUROC B`: Performance of Arm B.
  - `Difference (A − B)`: Paired AUROC delta.
  - `95% Bootstrap CI`: Confidence interval of difference using identical resample indices ($B = 2000$).

### Table 5: False-Positive Audit Across Lookalike Types
- **Goal:** Reveal what causes false alarms. Specifically, does talk alone (Type 3) mislead the monitor when only reading text, and does parallel conduct alone (Type 4b) mislead the monitor when only reading actions?
- **Source CSV:** `study_2_2_views/results/rq3_fpr_by_type_test.csv`
- **Columns:**
  - `View`: V1, V2, V3, V4, V5.
  - `Lookalike Type`: Type 2 (Honest), Type 3 (Talk-only), Type 4b (Same-incentive).
  - `n Negatives`: Available negative games in test split.
  - `False Positives (FP)`: Absolute count of innocent games flagged as collusive.
  - `FPR`: False positive rate ($\text{FP} / n$).
  - `Upper 95% Bound`: Hanley & Lippman-Hand Rule of Three ($3/n$) when $\text{FP} = 0$.

### Table 6: Colluder Identification & Localization Accuracy
- **Goal:** Audit whether the monitor can correctly pinpoint the guilty pair among the 10 possible pairs in collusive games.
- **Source CSV:** `study_2_2_views/results/rq8_top1_pair_test.csv`
- **Columns:**
  - `Source`: Monitor V1, V2, V3, V4, V5 (`suspected_pair`), and Deterministic Argmax of Code Signal (`Dep`).
  - `Type 1 Games (n)`: Number of collusive test games.
  - `Correct Pair`: Number where predicted pair exactly matches ground truth focal pair.
  - `No Pair / Abstain`: Number where monitor tied or abstained.
  - `Top-1 Accuracy`: Fraction of exact matches.

### Table 7: Legal-Style & Algorithmic Decision Rules (Study 2.3)
- **Goal:** Compare traditional antitrust evidentiary frameworks ("parallel conduct plus plus-factors") against standalone talk, standalone economics, and machine learning rules.
- **Source CSV:** `study_2_3_evidence/results/decision_rules_test.csv` (generated from `core/evidence/signals.py`)
- **Columns:**
  - `Rule ID & Name`: R1 (Talk only: $C_{\text{judge}}$), R2 (Gain only: $G_{\text{others}}$), R3 (Dependence only: $\text{Dep}$), R4 (Legal Style: Parallel Conduct + Plus Factor), R5 (Conjunctive: Gain + Dependence), R6 (Points Scoring: $k$ families), R7 (L2-Regularized Logistic Regression).
  - `AUROC`: Test discriminative capability.
  - `95% CI`: Bootstrap CI.
  - `Threshold / Parameters`: Frozen dev parameters.
  - `Test Accuracy / TPR / FPR`: Operating characteristics.

### Figure 1: ROC Curves for Information Representations (V1, V2, V3, V4, V5, C-mismatch)
- **Goal:** Visually demonstrate the trade-offs across the entire decision threshold spectrum, illustrating whether the combined representation (V3) strictly dominates text-only (V1) and action-only (V2).
- **Source Data:** Raw score tables from `runs/study_2_2/test/scores.csv` joined with `data/labels.csv`.
- **Plot Details:** Sensitivity (TPR) on the y-axis vs 1 − Specificity (FPR) on the x-axis for V1 (blue dashed), V2 (red dotted), V3 (green solid), V4 (purple dash-dot), and C-mismatch (gray solid baseline).

### Figure 2: Evidence Signal Distributions by Episode Condition
- **Goal:** Illustrate how the underlying evidentiary signals separate real collusion from the two lookalikes.
- **Source Data:** `core/evidence/pair_signals.csv` or `game_signals.csv`.
- **Plot Details:** Multi-panel boxplot or scatter:
  - Panel A: Action dependence ($\text{coGO}$ / $\text{capture}$) separating Type 1 & 4b from Type 2 & 3.
  - Panel B: Economic advantage ($G_{\text{others}}$ / $\text{Harm}$) across conditions.
  - Panel C: Communication coordination ($C_{\text{kw}}$ / $C_{\text{judge}}$) separating Type 1 & 3 from Type 2 & 4b.
  - Panel D: Joint word-action deviation ($W_{\text{joint}}$) demonstrating real collusion's unique signature.
